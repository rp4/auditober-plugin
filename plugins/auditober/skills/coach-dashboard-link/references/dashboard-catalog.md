## Filter rules and routing

- **AI Activity**: Suggestion usage and outcome movement scope=enterprise or a live active item-type slug, lowercased. Repeat `filter=...` for multiple selections; do not comma-join these keys. Table sort uses <sortKey>.<asc|desc>; choose a listed value exactly. Fixed values: `range=6m|12m|ytd`; `USER_OUTCOMES.sort=approved.asc|approved.desc|rejected.asc|rejected.desc|pending.asc|pending.desc|failed.asc|failed.desc|total.asc|total.desc`; `STEP_REJECTIONS.sort=reviewed.asc|reviewed.desc|rejected.asc|rejected.desc|rejectionPercent.asc|rejectionPercent.desc`.
- **Audit Plan**: Audit plan by year (2000–2100). Use year, not fy, range or audit.
- **Capacity Monitoring**: Owner workload, due work, and late work scope=enterprise or a live active item-type slug, lowercased. Repeat `filter=...` for multiple selections; do not comma-join these keys. Fixed values: `range=6m|12m|ytd`.
- **Compliance Requirements**: Requirement applicability and implementation. Resolve framework tokens live and use the declared applicability/implementation values.
- **Executive**: Enterprise assurance posture and decisions scope=enterprise or a live domains option from control, risk or policy, lowercased. Repeat `filter=...` for multiple selections; do not comma-join these keys. Fixed values: `range=6m|12m|ytd`.
- **Issues Remediations**: Open issues, overdue remediation and validation. Only audit and fy filter the URL. past_due means the earliest open linked remediation target is before today. For overdue-only answers select issues.dueState=past_due and use daysLate/counts.pastDue; check issuesCapped and linksCapped before claiming complete coverage. Link the wider view as context.
- **Item type register**: A verified active register row supplies configJson.itemTypeSlug. range=6m|12m|ytd; fieldFilters is a JSON object of live field keys to string arrays; filter is a returned selection key. Never infer an available register from item-type-register alone. Repeat `filter=...` for multiple selections; do not comma-join these keys. Fixed values: `range=6m|12m|ytd`.
- **Model Inventory**: Model register and assurance. Resolve the model item represented by the selection live.
- **My Work**: A prioritized view of work requiring action scope=enterprise or a live active item-type slug, lowercased. Repeat `filter=...` for multiple selections; do not comma-join these keys. Fixed values: `range=6m|12m|ytd`.
- **Operational**: Workflow throughput, delay, and accumulated work scope=enterprise or a live active item-type slug, lowercased. Repeat `filter=...` for multiple selections; do not comma-join these keys. Fixed values: `range=6m|12m|ytd`.
- **Personnel**: People and reporting lines. focus is a live personnel item ID; template is a live template ID; first=6|12|24; after is an opaque returned cursor. Clear after when focus or template changes. Fixed values: `first=6|12|24`.
- **Policy Exceptions**: Policy waiver approvals and expiry. scope=open|all; type/framework refer to the waived policy. Fixed values: `scope=open|all`.
- **Policy Lifecycle**: Policy review workflow, calendar, owner and status. Resolve type/framework/owner/status live; review uses the checked fixed tokens. Fixed values: `review=overdue|due|due_30|due_60|due_90|later|no_date`.
- **Risk Control Matrix (RCM)**: Risk and control coverage for an audit. entity is its live audit ID. RCM_MATRIX filter values come from systemDashboardTable.filterOptions; scope has no domain selector. Repeat `filter=...` for multiple selections; do not comma-join these keys. Table sort uses <sortKey>.<asc|desc>; choose a listed value exactly. Fixed values: `range=6m|12m|ytd`; `RCM_MATRIX.sort=item.asc|item.desc|audit.asc|audit.desc|coverage.asc|coverage.desc|signedOff.asc|signedOff.desc`.
- **Risks**: Open risks, treatment, owner and linked work. categories/treatments use live field options; none means no treatment; templates are risk-template IDs.
- **Sox Program**: Current SOX program. controls=key|all; key is the default. Legacy coverage parameters redirect to Workflow Coverage and must not be added here. Fixed values: `controls=key|all`.
- **Template Runs**: Workflow runs by selected template. Up to 12 bare live template IDs; range=6m|12m|24m (12m default). month=YYYY-MM and state=complete|open travel together. Fixed values: `range=6m|12m|24m`; `state=complete|open`.
- **Third Party Risk**: Vendor systems by tier and review progress. scope=vendors|all (vendors default); tiers use live system.tier tokens; up to 12 live system-template IDs; q is search. Fixed values: `scope=vendors|all`.
- **Universe**: Graph and focus views. Dynamic selectors come from universeData.nodeTypes. Any selector creates a complete snapshot including all ordinary fields and four synthetic types; preserve explicit empty values. Verify focus via universeFocus. Fixed values: `window=7d|30d|90d|1y`.
- **Workflow Coverage**: A view requires contextItemType, context (live item ID), and relatedItemType. q, coverage and workflows use the resulting view’s live groups.

Unsupported filters must be answered through query_data rather than appended to a URL.
For overdue issues, report the returned overdue population and link Issues and remediations
as context. Never label that whole page an overdue-only view. Counts/list limits and cap flags
must be checked; an incomplete read is not a zero result or complete list.
